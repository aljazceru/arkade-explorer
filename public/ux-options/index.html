Selected direction:
B — Operator Console.

Refined around record inspection rather than terminal aesthetics: restrained color, readable typography, a persistent detail panel, and source evidence on demand. This is still a standalone design prototype; the production React UI has not been replaced.

What the prototypes demonstrate
  • Three different information architectures, not three color themes. Layouts adapt to narrow screens; tables scroll within their own region.
  • Working fixture search/filtering and record inspection. Prototype state does not affect your real watchlist or wallet.
  • Explicit separation of virtual transactions, on-chain commitments, active expiry, settled records, unknown evidence, and stale snapshots.
  • Future implementation must preserve full integer precision, validate metadata and stored state, and compute expiry from current evidence. A visual redesign alone does not fix these issues.
